# Task5

Лабораторная работа: разработка и модульное тестирование системы банковского счёта.
Python 3, тесты на стандартной библиотеке `unittest`. Устанавливать зависимости не нужно.

## Возможности

Класс `BankAccount` хранит имя владельца, номер счёта и баланс. Новый счёт
создаётся с нулевым балансом.

- `deposit(amount)` — пополнение.
- `withdraw(amount)` — снятие.
- `transfer(other_account, amount)` — перевод другому счёту.
- `get_balance()` — получение баланса.
- `is_empty()` — проверка нулевого баланса.

Сумма операции должна быть положительным конечным числом. При неверной сумме,
недостатке средств или неверном получателе возникает `ValueError`.
Перевод на свой же счёт запрещён. Проверки выполняются до изменения балансов.
Для точного хранения десятичных сумм используется стандартный тип `Decimal`.

## Пример

```python
from bank_account import BankAccount

sender = BankAccount("Эльдар", "001")
receiver = BankAccount("Анна", "002")
sender.deposit(1000)
sender.withdraw(100)
sender.transfer(receiver, 250)

print(sender.get_balance())    # 650
print(receiver.get_balance())  # 250
print(sender.is_empty())       # False
```

## Запуск тестов

Из папки проекта:

```bash
python -m unittest -v
```

Тесты находятся в `test_bank_account.py` и проверяют создание счёта,
пополнение, снятие, перевод, получение баланса, пустой счёт и обработку ошибок.
Отдельно проверяется, что при неудачном переводе оба баланса сохраняются.
